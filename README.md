# Morgan's On Main — Premium GitHub Pages Website

Static multi-page restaurant website concept built for GitHub Pages.

## Pages
- Home
- Our Story
- Menu
- Bar
- Gallery
- Events & Catering
- Visit

## Deploy
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Open Settings → Pages.
4. Select `Deploy from a branch`, choose `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Image note
The site references publicly accessible image assets surfaced from Morgan's On Main's current public website/CDN. For a client-approved production launch, the restaurant should confirm permission to use its photography and brand assets.
